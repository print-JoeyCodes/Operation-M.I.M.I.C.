# Operation-M.I.M.I.C.
Modulating Intercepted Master Infrared Codes 

I'm building a PCB to integrate IR receiving and sending to emulate a laser gun. 
I am using a vs1838b IR reciver to capture the signal codes fired from my laser gun.
And then processing them and storing the raw data with an ESP32 dev board.
Then, by using some buttons to navigate menus, I can fire the signal out at other laser guns.

This project exists because when my dad bought a laser gun set for Christmas, it was fun to play with, but it lacks interactions other than just shooting people.
With this PCB, I can create custom guns, and even a BASE that you can shoot and claim all with just code because I will have the baseline components set up.
